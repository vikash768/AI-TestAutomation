Test an application

One per line: the app's code first, then (optional) its backend API.

Every write the browser tries to make (POST, PUT, PATCH, DELETE) is intercepted and never reaches the server; only sign-in, token refresh and the logout test go through. Destructive actions only have their confirmation opened and cancelled. Credentials are encrypted at rest and wiped when the run finishes.

Native runs go to the host worker (make app-worker-start), which drives Appium on this machine: Android via UiAutomator2 on a connected device or emulator, macOS via Mac2. Only controls classed safe from their label and the code are tapped: anything that saves, uploads, syncs, deletes, signs out or leaves the app is held back and listed. Typed test input is never submitted and the original value is put back. Credentials are encrypted at rest and wiped when the run finishes.
